# Sprint 11 public report reproduction

Sprint 11 publishes a deterministic view of two accepted evidence sets:

1. the Sprint 5 local controlled experiment; and
2. the Sprint 10 single-transaction Devnet integration validation.

These datasets remain separate. Devnet is not added to the controlled
experiment denominator and the local controlled classifications are not
generalized to public providers.

## Requirements

- Node.js `22.17.0`
- pnpm `11.16.0`
- the committed repository fixtures

Rust and Agave are required to rerun the original live experiments, but not to
verify the frozen public report.

## Verify the committed report

```powershell
corepack pnpm@11.16.0 install --frozen-lockfile
corepack pnpm verify:sprint-11
```

The verifier:

1. builds and typechecks the workspace;
2. runs all deterministic tests;
3. reverifies all 600 accepted Sprint 5 observer signatures;
4. rederives all twelve Sprint 5 scenario summaries byte for byte;
5. reconstructs the accepted Devnet lifecycle from raw JSONL;
6. inventories and hashes every retained source file;
7. regenerates Markdown, canonical JSON, CSV, and the report manifest; and
8. fails if any generated byte differs from the committed report.

## Deliberately regenerate after an accepted evidence change

```powershell
corepack pnpm report:sprint-11
corepack pnpm verify:sprint-11
```

Regeneration is not an evidence migration mechanism. Any changed fixture must
first pass the acceptance process for the sprint that owns that evidence. A
changed source hash without an explicit evidence decision invalidates the
published report.

## Outputs

- `reports/public-experimental-report-v0.1/report.md`
- `reports/public-experimental-report-v0.1/report.json`
- `reports/public-experimental-report-v0.1/report.csv`
- `reports/public-experimental-report-v0.1/manifest.json`

The manifest fingerprints all inputs and report outputs with SHA-256. It does
not hash itself, avoiding a circular digest.
