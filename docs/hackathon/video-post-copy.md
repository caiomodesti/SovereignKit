## Devpost / YouTube description

An RPC acknowledgement is not proof that a Solana transaction landed.

SovereignKit is open-source infrastructure for controlled transaction
accessibility experiments, independently observed lifecycles, reproducible
route-asymmetry evidence, and bounded fail-open routing.

This demo replays HEALTHY, DEGRADED, and ASYMMETRIC accepted fixtures, shows a
real finalized Devnet integration transaction, and preserves the limitations of
the evidence instead of turning a controlled result into a universal claim.
