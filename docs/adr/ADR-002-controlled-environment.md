# ADR-002: Controlled local environment first

- Status: Accepted
- Date: 2026-08-10

## Decision

The initial scientific experiment uses a project-controlled local validator, project-owned test program, and controlled proxies. Devnet is reserved for later integration validation.

## Consequences

The intervention is deterministic and reproducible, but findings cannot be generalized to third-party infrastructure or public-cluster censorship. Reports must label the environment prominently.
