# ADR-013: Apache-2.0 license

- Status: Accepted
- Date: 2026-08-11

## Decision

License SovereignKit under Apache-2.0. The explicit patent grant is appropriate for infrastructure intended for integration by wallets, RPC systems, and other ecosystem software.

## Consequences

Redistributions must preserve license and notice obligations. Contributions are governed by Apache-2.0 unless a future contribution policy adds compatible terms.
