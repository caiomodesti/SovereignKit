# ADR-012: Formal GO/KILL checkpoint

- Status: Accepted
- Date: 2026-08-10

## Decision

After the Asymmetry Engine and experiment summaries, stop and evaluate the mandatory gates in `docs/go-kill-checkpoint.md`. Dashboard and public infrastructure require an explicit GO.

## Consequences

The project can be killed or pivoted before presentation work hides a failed measurement thesis. Schedule pressure is not grounds to waive a gate.
